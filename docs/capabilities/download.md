# `rget` 下载与 `rdo` 预览

远端恢复环境会安装 `rget` 和 `rdo`。它们通过当前 `tssh` 会话的本地下载桥将远端文件传回
本机；目标机不需要安装 `tssh`、rsync 或常驻 Agent。

## 下载文件

```bash
rget ./report.pdf
rget ./a.txt ./b.txt
rget '/work/results/*.csv'
```

路径可以是远端绝对路径或相对于远端当前目录的路径。多个文件按顺序传输，每个文件都使用
原有的单文件下载协议，因此缓存命中、状态、进度、断点续传和失败处理保持一致。批量任务
显示当前文件序号及其进度；遇到失败后停止，之前成功下载的文件仍留在本机缓存中。

## 递归下载目录

```bash
rget -r ./results
rget --recursive '/work/data/**/*.csv'
```

目录必须显式使用 `-r`/`--recursive`。目录树会展开为普通文件，并保留每个文件的远端绝对
路径身份，因此不同目录中的同名文件不会互相覆盖。符号链接目录不会递归跟随。空目录或
没有匹配项会报错。

通配符由远端 `rget` 展开。建议将含 `*`、`?` 或 `[]` 的模式加引号，避免远端 shell 先行
展开；未加引号时，shell 已展开的多个路径也可直接传给 `rget`。如果路径以 `-` 开头，使用
`--` 分隔选项和路径：

```bash
rget -- '-generated.txt'
```

## 本地缓存与续传

下载内容按远端 endpoint 和远端绝对路径确定缓存位置。重复请求会校验远端文件状态并复用
一致的缓存；大文件下载中断后，后续请求会从匹配的 `.part` 临时文件继续传输。每个文件
继续使用既有下载桥请求，所以不会把批量任务改成一个不兼容的新协议，也不会破坏 `rdo` 的
缓存与打开行为。

## 预览单个文件

```bash
rdo ./report.md
rdo '/work/papers/final.pdf'
```

`rdo` 仍只接受一个文件，并在下载完成后调用本机配置的预览器。批量预览不属于 `rdo` 的
语义；需要批量传回文件时使用 `rget`。
